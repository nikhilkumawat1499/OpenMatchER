# Roadmap

## 0.1

- Local deterministic entity resolution.
- CSV, JSON, and Parquet upload.
- Project and run management.
- Cluster review UI.

## 0.2

- Prefect worker execution.
- Export endpoints.
- Human review decisions persisted as labels.
- LightGBM and XGBoost training jobs.

## 0.3

- Embedding similarity in default pipeline.
- Model registry and experiment tracking.
- Advanced RBAC.
- Spark-native candidate generation.
- Human-in-the-loop active learning queues.
- Public benchmark leaderboard.

## Future

- Spark execution adapter.
- Object storage adapters.
- Active learning.
- OpenSearch-backed candidate retrieval.
- Billion-record partitioning and shuffle optimization playbooks.
- Community plugin system.
