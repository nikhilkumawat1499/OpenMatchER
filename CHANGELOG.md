# Changelog

All notable changes to OpenMatchER are documented here.

## 0.2.0 - Open Source Maturation

- Added Makefile commands for startup, testing, linting, formatting, and benchmarks.
- Added benchmark framework and generated leaderboard assets.
- Added local and Spark execution engine abstractions.
- Added dataset versioning, experiment tracking, review decision, and audit-log models.
- Added advanced LLM adjudication schema with risk levels and malformed-output retry.
- Added demo datasets for companies, people, universities, and products.
- Added scalability, threat model, research, and blog documentation.
- Added CSV export and upload-size enforcement.

## 0.1.0 - Initial Release

- FastAPI backend, Next.js frontend, matching engine, LLM provider abstraction, Docker Compose, CI, docs, tests, and sample datasets.
